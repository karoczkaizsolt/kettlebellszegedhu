# 02 – Layout & Design: milestone report

Status: implemented, awaiting design-owner approval. No interactions were implemented (the Spline scene's own interactions are untouched; the page-state wiring, video modal behaviour and promo bar timing are milestone 03).

## What was built

- **Project:** Astro 7 + TypeScript, static output. Dependencies: `astro`, `@splinetool/runtime` (lazy-loaded), dev: `typescript`, `@astrojs/check`. Git initialised and connected to the remote (no commit, no push).
- **Page:** one landing page (`src/pages/index.astro`) with desktop (≥ 960 px) and mobile layouts built from the Figma frames (desktop 1280×834, mobile 393×872), fluid between them, no horizontal overflow from 320 px to 1920 px.
- **Components** (`src/components/`): `PromoBar`, `SplineScene`, `Hero` (H1, headline texture, StrongFirst logo), `Tags`, `InfoBanner`, `VideoTab`, `Credit`, `VideoModal`. Styles: `src/styles/tokens.css` (Figma variables), `fonts.css`, `global.css`.
- **Static states:** default and active states exist as CSS driven by one attribute on `<html>` (`data-state="default|active"`). For review it was set by script; in milestone 03 it will mirror the Spline `kettlebellLifted` variable.
- **Fonts:** Basement Grotesque Black (original OTF), Sometype Mono 400/500/600 (one variable woff2) and Italic 400, each in latin and latin-ext, served locally.
- **Assets from Figma (approved exports):** headline textures (desktop/mobile), 88×88 avatar (served as optimized WebP), icons, video poster. Logo: the existing SVG, used as a CSS mask coloured `#80818B` (default) / `#807369` (active).
- **Environment/config** (`src/config.ts`, `.env.example`): demo vs production by configuration only. Demo build: `noindex, nofollow`, no canonical. Production build: canonical `https://kettlebellszeged.hu/`, no robots meta. Video URL from `PUBLIC_VIDEO_SRC`. Nothing hardcodes a demo URL.
- **Video:** web version generated by `scripts/encode-video.sh` (720p, H.264, +faststart): 68 MB → 21 MB. It is written to `public/video/` (git-ignored). The original is untouched.
- **Git safety:** `.gitignore`, `scripts/check-no-video.mjs`, `.githooks/pre-commit` (activated with `core.hooksPath`; also set automatically by `npm install` through the `prepare` script).
- **Asset sync:** `scripts/sync-assets.mjs` copies the scene, logo and fonts from `assets/` into `public/` before dev/build (generated, git-ignored).

## Spline scene: sizing, position and background

- The scene is loaded after the first render, only when a WebGPU adapter exists. **It was exported for WebGPU only**, so browsers without WebGPU get the static fallback (the runtime is then not downloaded). Re-exporting with renderer "Both" is recommended (design-owner decision, not done).
- The scene is not modified. The canvas is opaque: the scene paints its own backdrop (dark; warm gold when lifted). The CSS background (dark; dark-brown to orange) matches that look and shows only at the canvas edges and in the fallback.
- Placement (CSS only), derived from the Figma frames: desktop canvas is full-bleed, shifted down 7.2% with a 96 px fade at its top edge; mobile canvas box is 11% from the top, 87.5% high.

## Known differences and open points

1. **Mobile kettlebell** is about 8% larger than in the Figma frame (body ≈ 233 px vs 216 px). Accepted by the design owner; the Spline camera is not changed.
2. **Lifted kettlebell vs logo (desktop):** in the review screenshot the raised kettlebell's handle touches the logo; in Figma there is a gap of about 10 px. This depends on the scene's lift height/animation phase, which is part of the scene.
3. **E-mail button:** address `kettlebellszeged@gmail.com` (provided by the design owner) is the default in `src/config.ts`; `PUBLIC_CONTACT_EMAIL` overrides it. The phone button links to `tel:+36309833750`.
4. **Credit line (© Varga Tamás • KZS Design):** desktop only, hidden on mobile (design-owner decision). The text appears on hover/focus of the info icon, as in Figma.
5. **Promo bar on mobile** wraps to two lines (there is no mobile frame for it). It is hidden until the timing logic of milestone 03.
6. **Headline overlay in the active state** switches without a transition (a CSS background image cannot be animated); everything else transitions. Can be refined in milestone 03 if wanted.
7. **Dividers** are drawn as 1 px CSS lines with the Figma colours instead of the exported line SVGs.
8. **Video player** uses the native controls (play/pause, volume, fullscreen), so the player is visually minimal but not identical to the Figma still, which shows no controls. The poster is the Figma still (WebP), not a frame from the encoded video.
9. **No favicon** yet (console 404 for `/favicon.ico`); icons and metadata are part of milestone 04.
10. **Not yet in this milestone** (by plan): interaction wiring (hover/tap to page state), video modal behaviour (focus, ESC, scroll lock, stop on close), promo bar timing, SEO files (sitemap, robots.txt, JSON-LD), accessibility audit.
